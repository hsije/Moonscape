# Moonscape
# 🌙 MoonSpace (月空间) - AI 情绪可视化避风港

> **"不打分，不选标签，让情绪在岛屿上生长。"**
> 
> MoonSpace 是一款以《光遇》的静默陪伴为视觉基调，融合 Apple Liquid Glass 透镜美学的 AI 生成艺术应用。用户通过意识流输入（文字、语音、歌曲），AI 实时生成可视化的“心境之岛”，将抽象情绪转化为长期演化的数字资产。

---

## 🧠 核心产品理念 (Design Philosophy)

### 1. 情绪即景观 (Emotion as Landscape)
摒弃传统的图表与标签，AI 依据语义、语调与氛围将情绪具象化：
- **焦虑** → 灰蓝的快速电子云与崎岖地貌
- **平静** → 淡绿的水母与平缓海岸
- **孤独** → 星空孤岛与一盏暖灯
- **喜悦** → 瞬生花与种子层

### 2. 极简交互纪律 (Discipline of Interaction)
**UI 是透镜，而不是面板。** 我们禁用了所有传统社交软件的“毒性”设计：
- ❌ 无未读红点、无“正在输入”、无强制文字回复
- ❌ 无打分标签、无解释性大面板
- ✅ 控件漂浮、半透明，长按元素浮起凝胶薄膜，松手被吸收（无进度条）
- ✅ AI 发言不弹对话框，景观表面浮现玻璃高光，触碰后文字缓慢溶解浮现

### 3. 静默陪伴社交 (Silent Companionship)
- **漂流瓶 2.0**：发送岛屿片段，对方进入微型景观，聆听当时的氛围音。
- **共栖空间**：双方同时在线时，液态玻璃“预流”凝固为桥，看到对方实时投影，无需说话。
- **低压互动**：仅“点亮一盏灯”“种下一朵花”，以光学浓度表达在场。

### 4. 情绪清理与疗愈 (Therapeutic Release)
- **情绪垃圾桶**：负面情绪通过火山爆发等仪式释放，转化为地热、玄武岩地基与温泉。
- **AI 镜像对话**：AI 仅作为“观察者”，默认沉默，通过灯色、鸟飞走等微小环境变化回应。
- **永久不回应权**：AI 可被永久静音，沉默被完整支持。

## 🛠 技术栈与架构 (Tech Stack)

本项目致力于构建一个**高沉浸感、实时渲染**的 Web 3D 体验：

- **前端渲染**：`Three.js` / `React Three Fiber` (R3F) - 实现复杂的岛屿地貌与粒子系统
- **视觉特效**：`Shader (GLSL)` - 实现 Liquid Glass 的折射、色散与凝胶弹性
- **AI 引擎**：`LLM API` (如 OpenAI / Claude) + `Web Speech API` - 语义情绪分析与语音识别
- **状态管理**：`Zustand` / `Redux Toolkit` - 处理复杂的岛屿演化状态与生态层
- **后端/存储**：`Supabase` / `Firebase` - 用户资产与双岛同步
- **部署平台**：`Vercel` / `Netlify` (在线 Demo 体验)
